# E-Commerce Sales Forecasting: Product Behavior Analysis & Hybrid Machine Learning Approach

A high-precision sales forecasting system designed for chaotic e-commerce environments, utilizing a hybrid **Stacking Ensemble** architecture to manage extreme volatility and campaign-driven demand spikes.

##  Overview
Predicting daily sales in e-commerce is challenging due to sudden promotional "spikes," high volatility, and non-linear demand patterns. This project implements a hybrid architecture that combines statistical rigor with deep learning flexibility to optimize stock management, prevent stock-outs, and reduce inventory holding costs.

##  Dataset & Preprocessing
* **Raw Dataset Size:** 1,067,371 rows × 8 columns spanning approximately 2 years (739 days).
* **Target Variable (`Günlük Toplam Ciro`):** Generated by calculating transaction-level totals using quantity and unit price, then aggregating them daily.
* **Data Cleaning:** Filtered down to ~397,000 cleaned records and aggregated into a 739-day continuous time series.
* **Volatility:** Exhibits an extreme Coefficient of Variation (**CV: 86.2%**), reflecting high noise and massive promotional spikes.
* **ABC Analysis (Pareto Principle):** 
  * *A-Class:* 80% of revenue.
  * *B-Class:* 15% of revenue.
  * *C-Class:* 5% of revenue.
* **Data Split:** 651 days (91.5%) for training and 60 days (8.5%) for testing[cite: 2].
* **Transformations:** Logarithmic transformation (`np.log1p`) applied for tree-based models and MinMax scaling applied for neural networks[cite: 2].

##  Hybrid Stacking Ensemble Architecture
The core of this system is a two-layer **Stacking Ensemble** that blends individual model strengths[cite: 2]:

* **Layer 1 (Base Learners):**
    * **SARIMAX (Baseline):** Utilized 1st-order differencing ($d=1$) for stationarity and captured 7-day weekly seasonality using Fourier terms[cite: 2].
    * **Log-XGBoost:** Excelled at capturing non-linear feature interactions and handling campaign-driven demand shocks with the lowest individual MAE[cite: 2].
    * **Multivariate Bi-LSTM:** Configured with a Huber Loss function to handle outliers and capture sequential dependencies[cite: 2].
* **Layer 2 (Meta-Learner):**
    * **Ridge Regression:** Harmonizes predictions from base learners ($w_1(\text{XGBoost}) \approx 0.72$, $w_2(\text{Bi-LSTM}) \approx 0.28$, $\text{intercept} \approx 0.12$) to produce a stable final forecast[cite: 2].

The hybrid Stacking Ensemble significantly outperforms baseline statistical models, achieving the highest overall **$R^2$ score of 0.7361**[cite: 2].

##  Key Contributions & Features

* **Commercial Value:** Established a robust Decision Support System (DSS) for A-Class products under 86.2% volatility, optimizing inventory and storage costs[cite: 2].
* **Academic Contribution:** Successfully integrated statistical time series, gradient boosting, and deep learning into a cohesive Stacking framework for retail demand forecasting[cite: 2].
